# EBFI Ops

Внутренняя система EBFI Engineering Bureau International: заявки, Табель работ, финансовые результаты по месяцам, реестр исходящих счетов (инвойсы клиентам с GST), реестр TDS, реестр входящих счетов (счета инспекторов) и дашборд. Заменяет четыре Google Таблицы с 1 декабря 2026.

Текущая дата во всей системе — время Индии (IST, Asia/Kolkata); часы показаны вверху справа.

## Разделы

| Раздел | Что в нём |
| --- | --- |
| Дашборд | KPI, выручка и прибыль по месяцам, клиенты, регионы, координаторы, инспектор, счета |
| Заявки | Входящие запросы клиентов. Открываются на текущем месяце. Переносятся в Табель кнопкой «В Табель →» из любого статуса, кроме «Отмена» |
| Табель | Одна строка — одна работа: клиент, инспектор, завод, страна, «Чья», даты, MD, ставки клиента и инспектора. Отчётный месяц (по умолчанию текущий) и фильтр «Активные / Завершенные / Все» |
| Финансовые результаты | Помесячный расчёт по работам, закрытие месяца |
| Реестр исходящих счетов | Инвойсы клиентам: GST, WHT, статусы оплаты, «Инвойс из работ» |
| Реестр TDS | TDS, удержанный индийскими клиентами |
| Реестр входящих счетов | Счета инспекторов: сверка с Табелем, PDF, отметка оплаты |
| Справочники | Клиент, Финальный клиент, Инспектор, Завод (Vendor), Курс валют, Налоги и нумерация, Метод оплаты, Страна |

Статусы работы: «В работе», «Пауза», «Завершен».

### Продление работы на следующий месяц

Кнопка «Продлить на следующий месяц» в карточке работы — когда работа продолжается в новом месяце под новым номером. Создаётся новая работа: номер — следующий в очереди клиента, тот же клиент, контакт, Client Job Number, завод, страна, «Чья», тип услуги, оборудование, груз; отмеченные инспекторы с их ставками, валютами, единицей и методом оплаты. Даты — уже внесённые на следующий месяц (они переходят из старой работы) или введённые в окне. Старая работа остаётся с днями своего месяца и со своим статусом (её завершают как обычно, когда пройдут её даты) и выставляется клиенту как обычно; overtime, файлы и инвойсы остаются в ней. В карточках обеих работ — ссылки «Продолжение работы …» / «Продолжена как …». Доступно в любой момент.

### Табель по отчётному месяцу

- Табель показывает выбранный месяц: только работы с днями в этом месяце, а в колонках «Дата» и «MD» — только дни этого месяца. Работа через несколько месяцев видна в каждом из них своей частью. «Все месяцы» — вся история.
- Работа без дат в Табель не попадает: даты обязательны при создании работы и при переносе из заявки. Визит или фиксированная сумма относятся к месяцу даты визита.
- Значок «даты прошли» — последняя дата работы прошла, а она не завершена. Незавершённые работы, у которых все даты в прошлых месяцах, перечислены над Табелем отдельной строкой со ссылками.
- Статус работы меняется прямо в карточке (переключатель «В работе / Пауза / Завершен»), не через «Изменить данные работы».
- Даты другого месяца, записанные в одну строку (например «30.11, 07.12, 15.12» из таблицы), при запуске раскладываются по своим месяцам.
- **Фиолетовая строка:**
  - месяц последней даты закрыт больше суток назад, а работа не «Завершен» — отметка уходит после завершения;
  - закрытый месяц работы изменён позже суток после закрытия (даты, MD, ставки, инспектор, клиент) — в карточке видно кто и когда; бухгалтер или админ снимает отметку кнопкой «Проверено».
- Закрытый месяц можно редактировать: его курсы и ставки налогов остаются зафиксированными, финансовые результаты пересчитываются. Статусы заявки: «В процессе», «Принято в работу», «Выполнено», «Перенос», «Отмена».

## На iPhone

ERP — веб-приложение, которое ставится на экран «Домой»: открыть адрес ERP в Safari → «Поделиться» → «На экран Домой». Открывается во весь экран с иконкой EBFI Ops, вход как обычно; обновления приходят сами.

На телефоне: нижняя панель «Дашборд / Заявки / Табель / Ещё», таблицы показываются карточками, формы и окна — на весь экран. В карточке работы «Загрузить» предлагает «Снять фото», медиатеку или «Файлы»; фото с камеры получает имя «<Job № дата время>.jpg». Значок скачивания рядом с файлом отдаёт его напрямую, без входа в Microsoft.

В Табеле и Заявках есть фильтр «Менеджер» (Все / Мои / конкретный менеджер). Фильтры не сбрасываются при переходе в другой раздел и при открытии работы: менеджер, статус и вид (карточки или список на телефоне) запоминаются насовсем, месяц и поиск — пока открыто приложение. Масштаб на телефоне зафиксирован.

## Мой день и утренняя сводка

«Мой день» (первая вкладка на телефоне): инспекции сегодня и завтра, отчёты за вчера к сдаче клиенту, работы, которые пора завершить, заявки «В процессе». Переключатель «Мои / Все».

Те же списки каждый день в 09:00 по Индии приходят в Telegram. Настройка: создать бота у @BotFather, вписать токен в `.env` как `TELEGRAM_BOT_TOKEN`, перезапустить. Каждый пользователь подключается сам: «Профиль → Подключить Telegram» → «Start» в чате с ботом; там же «Прислать сейчас» и отключение. Менеджеру приходят его работы, админу — все с пометкой «Чья».

## Автоматические подсказки

- **Инспектор занят.** При выборе инспектора и дат (новая работа, карточка работы, заявка, перенос в Табель) система показывает, в какие из этих дней он уже стоит на другой работе и на какой.
- **Счёт инспектора из файла.** В новой записи реестра входящих счетов «Заполнить из файла (PDF / Word)» читает номер, дату, сумму, валюту, дни, ставку, номера работ и инспектора; файл сохраняется вместе со счётом. Скан без текста заполняется вручную.
- **Удаление без вопросов.** Запись удаляется сразу, на подсказке внизу 6 секунд есть «Отменить».
- На телефоне список обновляется, если потянуть страницу вниз.

## Инвойсы клиентам (Word / PDF)

Правила и шаблоны — из проекта, где готовились инвойсы FY 2026-27: `backend/app/invoice_templates/` (`INSTRUCTIONS.md` — полная инструкция, `TPL_NN_<клиент>.docx` — шаблоны, `…_Annexure.xlsx` — для TUV Rheinland). Код правил — `app/invoice_rules.py`, сборка документа — `app/invoice_doc.py`.

1. **Шаблон клиента** — «Справочники → Клиент → Шаблон инвойса». Подставляется по названию при первом запуске; клиенту без шаблона (PANDA, IEBFI…) инвойс в Word не формируется.
2. **«Инвойс из работ»** — выбираете строки Табеля, система показывает шаблон, правила клиента и как строки разобьются: по валюте, по работе (TUV NORD, LRQA, Qatar, морские сюрвеи), по координатору (BV Singapore), не более ₹20 лакх с GST (TUV Rheinland India). Номера подряд, дата — последний день месяца работ (морские сюрвеи и DITH — день выставления).
3. **«Word / PDF»** в строке реестра — формирует документ: строки работ, Over-Time отдельной строкой, GST (CGST+SGST или IGST по шаблону), удержание 5% (Qatar), Annexure для TUV Rheinland; для морских сюрвеев — дополнительные строки (лаборатория, draft survey, пестициды). Файлы ложатся в `Outgoing Invoice Register/ГГГГ-ММ/<клиент>/EBFI-2627-NNN.docx / .pdf / _Annexure.xlsx`; повторное формирование заменяет их (номер тот же). Кнопки «Скачать Word / PDF» работают и без OneDrive.
4. Курс — курс месяца из «Курс валют», в инвойсе и в реестре округляется до 2 знаков. GST в реестре начисляется по галочке «Клиент из Индии» — если она расходится с шаблоном, окно инвойса предупредит.
5. Шаблоны можно править в Word: «Справочники → Хранилище → Положить шаблоны инвойсов на OneDrive» копирует их в `EBFI/Templates/Invoices`; ERP берёт файл оттуда, а если его нет — встроенный.

**Поля карточки работы для инвойса** (в таблице Табеля не показываются): «Тип услуги» (Inspection / Audit / Expediting → Inspection subject; при переносе берётся из заявки), «Оборудование» (Equipment), для морских сюрвеев «Тип груза» и «Тоннаж, MT». По тоннажу строка погрузки получает количество MT, а в окне «Word / PDF» кнопка «Подставить по грузу и тоннажу» добавляет лабораторию (кукуруза — 1 композит 750/795 $, остальное — тоннаж / 5000 лотов × 660 $ + пестициды 150 $) и draft survey (700 $ Аргентина / 600 $ Бразилия).

**Кредит-ноты** — раздел «Финансы → Кредит-ноты», только владелец и бухгалтер. CN-2627-NNN против инвойса: документ — копия инвойса с заголовком «CREDIT NOTE PASS AGAINST INVOICE № …» и датой кредит-ноты, файлы в `Outgoing Invoice Register/ГГГГ-ММ/<клиент>/Credit Notes/`. Кредит-нота отменяет инвойс полностью: он помечается в реестре, не считается к получению, его запись в реестре TDS удаляется (вернётся, если кредит-ноту удалить). Номер инвойса остаётся использованным. Номера кредит-нот, как и инвойсов, не повторяются — даже у удалённых. «Освободить работы» — работы можно выставить заново (другому плательщику или исправленным инвойсом). Последний выданный номер — «Справочники → Налоги и нумерация».

PDF делает LibreOffice в контейнере api (шрифт Liberation Serif — метрическая замена Times New Roman).

## Номера

- **Работа:** `ГГ.КК-ННН`. КК — код клиента из справочника «Клиент», ННН — очередь этого кода внутри года, с 1 января снова с 001. Номер подставляется автоматически, его можно поправить. Номер удалённой или возвращённой в заявки работы остаётся использованным.
- **Исходящий счёт:** `EBFI-<FY>-NNN`, одна очередь для всех клиентов. Автонумерация включается, когда админ вписывает последний выданный номер в «Справочники → Налоги и нумерация»; пока поле пустое, номер вводится вручную.

## Как считаются финансовые результаты

B = (количество × ставка клиенту + overtime клиенту) × курс валюты клиента за месяц, в INR. Подряд = (количество × ставка инспектора + overtime инспектору) × курс валюты инспектора: ставки клиента и инспектора могут быть в разных валютах.

| Показатель | Клиент из Индии | Клиент с WHT | Остальные |
| --- | --- | --- | --- |
| Приход на счёт | B + GST − TDS | B − WHT | B |
| GST (транзит, не выручка) | B × 0,18 | 0 | 0 |
| TDS (в реестр TDS, не расход) | B × 0,10 | 0 | 0 |
| WHT (удерживает клиент при оплате, никуда не зачитывается — **потеря**) | 0 | B × 0,05 | 0 |
| Админка | B × 0,18 | то же | то же |
| Подряд | количество × ставка инспектора × курс | то же | то же |
| РКО | по методу оплаты (пока 0) | то же | то же |
| **Чистая прибыль** | **B − админка − подряд − РКО** | **B − админка − подряд − РКО − WHT** | **B − админка − подряд − РКО** |

GST/TDS и WHT включаются галочками в карточке клиента («Клиент из Индии», «Удерживает WHT 5%»). Ставки меняются в «Справочники → Налоги и нумерация». Курс за месяц админ вносит по RBI в последний день месяца; до этого используется курс прошлого месяца с пометкой. При закрытии месяца курсы и ставки (включая WHT) фиксируются в строках.

Если даты работы идут через два месяца, работа сама делится между ними по дням. Даты понимаются в любом привычном виде: «05,06.11.2026», «16th, 17th & 20th Nov-26», «26/10/2026 to 29/10/2026».

## Файлы на OneDrive

ERP работает с папкой «My files → EBFI» в OneDrive админа через Microsoft Graph (приложение Entra «EBFI ERP», право Sites.Selected только на этот OneDrive). Настройки — в `.env`: `MS_TENANT_ID`, `MS_CLIENT_ID`, `MS_CLIENT_SECRET`, `MS_SITE_ID`, `MS_ROOT`.

```
EBFI/
  Server 2026/<ГГ.КК клиент>/<Job № Инспектор Страна Даты>/Inspection Documents, Inspection Deliverables
  Server 2026/_Cancelled/            удалённые и возвращённые в заявки работы
  Incoming Invoice Register/<ГГГГ-ММ>/<инспектор>/<работы — № счёта>.pdf
  Outgoing Invoice Register/<ГГГГ-ММ>/<клиент>/<EBFI-2627-NNN>.pdf
```

- Папка работы создаётся при создании работы и переименовывается при смене инспектора, страны или дат (ссылка не ломается). Папку, созданную вручную, ERP находит по номеру и привязывает как есть.
- Папка клиента ищется по коду (`26.29 …`); для новой создаётся с именем из поля «Папка на сервере» клиента или его названия.
- В карточке работы — блок «Документы на сервере» (список, загрузка, перетаскивание). В реестрах счетов — кнопка «Загрузить» / «Файл».
- Ошибка связи не мешает сохранить работу: она показывается в карточке с кнопкой «Повторить».
- `python -m scripts.files_sync --check | --numbers | --link` — проверка связи, сверка очередей номеров с папками на сервере, создание и привязка папок для работ с ноября 2026. «Справочники → Хранилище» делает первые две вещи из интерфейса.

## Роли

| Роль | Что может |
| --- | --- |
| админ | всё, включая пользователей и удаление любых записей справочников и реестров |
| бухгалтер | всё, кроме пользователей; удаляет заявки, работы, клиентов и финальных клиентов |
| менеджер | все данные, включая маржу, счета и статусы оплаты; удаляет заявки, работы, клиентов и финальных клиентов; без настроек и закрытия месяца |

Удаление везде мягкое: запись скрывается и остаётся в журнале изменений. Клиента нельзя удалить, пока на него ссылаются работы, заявки или исходящие счета. Админ и бухгалтер обязаны включить двухфакторную аутентификацию.

## Первая установка на сервер

Сервер: Ubuntu 24.04 с Docker.


## Импорт стартовых данных (октябрь и ноябрь 2026)

1. Скачать четыре Google Таблицы как Excel и назвать `pnl.xlsx`, `requests.xlsx`, `sales.xlsx`, `invoices.xlsx`.
2. Скопировать на сервер в `/opt/ebfi/app/import/`.
3. Запустить:
   ```bash
   docker compose exec api python -m scripts.import_xlsx --reset \
     --pnl /data/import/pnl.xlsx --requests /data/import/requests.xlsx \
     --sales /data/import/sales.xlsx --invoices /data/import/invoices.xlsx
   ```

Что попадает в систему:

- работы, заявки, исходящие и входящие счета только за октябрь и ноябрь 2026 (`--months` меняет набор месяцев);
- справочники из всей истории: инспектор (варианты написания объединяются, см. `scripts/names.py` и `MANUAL_MERGE`), клиент, завод, страна, финальный клиент (из колонки «Client Job Number / Client Name» Табеля и «final client» заявок);
- коды клиентов в номере работы и очереди номеров по годам;
- курсы USD и EUR за эти месяцы из колонки «$/€».

`--reset` стирает рабочие данные и справочники (пользователи остаются). Чтобы только дополнить справочники и ничего не стирать, вместо `--reset` укажите `--refs-only`.

## Обновление

На Mac: `git pull ../ebfi-ops-vNN.bundle main && git push` в папке `ebfi-ops`. На сервере:

```bash
cd /opt/ebfi/app && bash deploy/update.sh
docker compose ps        # у app-api-1 должно быть Up
```

Новые колонки базы добавляются автоматически при запуске (`backend/app/migrate.py`).

## Бэкапы

`deploy/backup.sh` каждую ночь сохраняет дамп базы, загруженные PDF и `.env` в `/opt/ebfi/backups` (30 дней). Восстановление базы:

```bash
docker compose exec -T db pg_restore -U ebfi -d ebfi --clean < /opt/ebfi/backups/db-2026-12-01.dump
```

Файл `.env` храните ещё и вне сервера: без `ENCRYPTION_KEY` банковские реквизиты инспекторов не расшифровать.
